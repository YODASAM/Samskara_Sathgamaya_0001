VIDEO PLACEHOLDER
=================
Upload your workshop / introduction video into this folder and name it:

    workshop.mp4

The webpage is already configured to load:
    assets/video/workshop.mp4

Recommended export:
- MP4 / H.264
- 16:9 landscape
- 1080p or 720p
- Keep the file reasonably compressed for faster page loading.

If workshop.mp4 is absent, the website shows the supplied yoga image as a poster and a friendly placeholder message.
